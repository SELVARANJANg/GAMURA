    How to remove a flagged file
    1. Windows: select the file, press Delete, then empty the Recycle Bin. Open Windows Security, then Virus & threat protection, and run a Quick scan.
    2. Mac: drag the file to the Bin and choose Empty Bin. Remove unknown apps from Applications.
    3. Android: open Files, long-press the file and tap Delete. In Play Store, open Play Protect and tap Scan.
    4. iPhone and iPad: delete the file in Files. Under Settings, General, VPN & Device Management, remove any profile you don't recognize.

    What Clearscan can and can't do

    • It checks the files you choose: known test signatures, SHA-256 hashes, disguised file types, risky names, macros, PDF scripts and suspicious script commands.
    • A web page can't read your whole device, running programs or memory, and it can't delete files. You remove flagged files yourself.
    • These are heuristics, not a full signature database. "No issues" is not a guarantee. Keep Windows Security, Play Protect or XProtect on.
